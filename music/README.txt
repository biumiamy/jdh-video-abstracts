Series music for every JDH video abstract: "Birds" by Corbyn Kites (YouTube Audio Library).

The mp3 is NOT in this repository: it may be used inside the videos, but must not be shared on its own.

To set it up:
1. Open the YouTube Audio Library (YouTube Studio -> Audio Library) and search for "Birds" by Corbyn Kites.
2. Download it and save it in this folder with exactly this name:
     Birds - Corbyn Kites.mp3
tools/render.py looks for that file name and adds the music to every rendered video.
